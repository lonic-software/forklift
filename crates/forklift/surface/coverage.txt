# Every operation the `forklift` binary had when this map was frozen (main 9c9abd21, the start
# of the command-surface redesign), with its parameters, and what each one became.
#
# A row is `forklift <command>: <parameters>`. While a command is unchanged, its row stands
# alone. When it moves, splits or changes a parameter, the row stays as it is and gains one or
# more indented `-> forklift <command>: <parameters>` lines, each a command that now carries part
# of the operation, so every change to a parameter is written down here rather than discovered.
# The surface check (crates/forklift/src/surface_check.rs) holds each destination to the binary,
# and fails on a command no row leads to.
#
# Parameters, in declaration order: <NAME> a required positional, [NAME] an optional one,
# `...` repeatable, -s/--long a flag, =<NAME> a value it takes, {a|b} the values it accepts,
# (hidden) not shown in help. The binary's own row holds the global options.
