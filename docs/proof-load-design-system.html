Proof Load Faceplate

This is the proposed look for the egui desktop app that runs fault scenarios and grades how Forklift and git come back from them. Every screen is built only from these tokens and components; anything the page lacks is added here first. Use the switch to flip themes, and every component on the page follows.

Theme

The decision: share pult-desktop's system or stand alone

decided: shared
Recommended

Share the Faceplate, add a grade family

  • Same tokens as pult-desktop: surfaces, ink, amber as the only interactive accent, Plex Sans and Mono, 6/10 px radius, 4 px grid.
  • The same rules apply: color says what happened and only failures latch.
  • Proof Load adds the five grade tokens below, each with its own glyph, because a grading matrix needs more than green and red.
  • The cost is that the tokens live in two places, CSS in pult-desktop and a Rust Theme struct here. A short parity test keeps the two copies in step.
Alternative

A standalone lab look

  • A flat, dense, table-first look with no raised pads and a neutral blue accent.
  • It is easier to make look native in egui (no inset shadows to fake), and it reads more as a test lab than as a hardware instrument.
  • The cost is that the lonic tools would no longer look like one family, and a second set of rules would have to be kept.

egui can draw everything on this page: rounded frames, strokes, flat fills and one shadow per frame. The raised and sunk pads use a 1 px highlight stroke and a 1 px shade stroke instead of real inset shadows. IBM Plex ships inside the binary, so every OS shows the same type.

Grades

oracle::Grade · worst first in sorting

Green is the only good color and red is the only bad one. The glyph tells grades of the same color apart, so the matrix still reads in grayscale or for color-blind users. Silent is the one latched state, an inverted plate that stays lit until it has been looked at, because it is the one outcome where the tool served wrong bytes and reported success.
